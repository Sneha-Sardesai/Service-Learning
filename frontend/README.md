# CSR Research Dashboard

This React/Vite client uses the Express API at `/api`. During development, Vite proxies API requests to `http://localhost:5000`.

From this directory:

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run build
```

Start the backend in a second terminal and configure MySQL before using company-management and research actions. See the repository [README](../README.md) for complete Windows setup, environment, database, CLI, API, and testing instructions.
